SAMMAN DIWAS MANAGER — GITHUB PAGES PWA

UPLOAD
1. Extract this ZIP on your computer.
2. Open GitHub and create/open a repository named Samman-Diwas-Manager.
3. Upload ALL files from this folder to the repository root. Do not upload the ZIP itself.
   Required: index.html, manifest.json, sw.js, icon-192.png, icon-512.png.
4. Commit changes.
5. Repository Settings > Pages.
6. Under Build and deployment choose "Deploy from a branch".
7. Select branch "main" and folder "/ (root)", then Save.
8. Wait for GitHub Pages to publish. URL format:
   https://YOUR-USERNAME.github.io/Samman-Diwas-Manager/
9. Open that exact URL in Chrome on the phone and check the app.
10. Chrome menu ⋮ > Install app / Add to Home screen.

IF THE OLD APP IS ALREADY INSTALLED
- Open and test the new GitHub Pages URL first.
- Remove the old shortcut/app only after the new site works.
- Install again from the GitHub Pages URL.
- If the old app persists, clear site data for the old host in Chrome settings, then reinstall.

IMPORTANT
- Local-only: records stay in this browser/device and do not sync across phones.
- Open online once so the service worker can cache files.
- Default PIN: 2468. Change it in Settings & Backup.
- PIN is a simple local lock, not secure authentication.
- Export JSON backups regularly; restoring replaces this device's current data.
- WhatsApp sharing opens WhatsApp with prefilled text; it does not send automatically.
- Use school-approved devices and avoid unnecessary sensitive student data.
